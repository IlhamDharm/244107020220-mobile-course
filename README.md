## Deskripsi

Repositori ini merupakan dokumentasi dan pengembangan proyek pembelajaran dalam mata kuliah Mobile Development menggunakan framework Flutter. Proyek ini dibuat untuk mendukung kegiatan perkuliahan, terutama dalam memahami dasar-dasar pengembangan aplikasi mobile, struktur proyek Flutter, serta penerapan antar muka (UI) yang responsif dan sesuai dengan prinsip desain modern.

## Tujuan

Tujuan utama pembuatan repositori ini adalah untuk:

- mempelajari ekosistem Flutter dan Dart;
- memahami struktur aplikasi mobile berbasis Flutter;
- menerapkan konsep UI declarative dan desain responsif;
- mengembangkan aplikasi sederhana yang relevan dengan kebutuhan pembelajaran.

## Struktur Repository

- `01-week-1=mobile-development-ecosystem-flutter-refresh/`  
  Folder ini berisi proyek pertama yang mencakup pengenalan ekosistem Flutter dan pembuatan aplikasi profil mahasiswa sederhana.

- `02-week-2=declarative-ui-responsive-design/`  
  Folder ini berisi latihan lanjutan terkait pemrograman UI declarative dan desain antarmuka yang responsif.

## Prasyarat

Sebelum menjalankan aplikasi, pastikan perangkat telah memiliki:

- Flutter SDK
- Dart SDK
- VS Code atau Android Studio
- Emulator Android/iOS atau perangkat fisik

Repositori ini masih dalam proses pengembangan sesuai dengan materi pembelajaran yang diberikan pada setiap sesi perkuliahan. Setiap perubahan dan penambahan materi akan dicatat secara bertahap sesuai perkembangan project.
